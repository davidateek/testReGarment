# Test Regarment

A simple, beautiful website hosted on GitHub Pages.

## Getting Started

This repository contains the source code for your GitHub Pages website.

### File Structure

- `index.html` - Your main homepage
- `styles.css` - Styling for your site
- `script.js` - JavaScript functionality
- `README.md` - This file

### How to Edit

1. Edit `index.html` to change your page content
2. Edit `styles.css` to customize the look and feel
3. Add more `.html` files in the root directory to create new pages
4. Commit and push to GitHub - your site updates automatically!

### Setting Up GitHub Pages

1. Push this repository to GitHub
2. In your repository settings, enable GitHub Pages:
   - Go to **Settings** > **Pages**
   - Select **main** (or **master**) branch as the source
   - Your site will be published to `https://yourusername.github.io/testReGarment`

### Tips

- Keep it simple - static sites load fast
- Use descriptive file names
- Test locally by opening `index.html` in your browser
- Commit frequently with clear messages
